# SOURCES · 信息源清单

> 原则：来源要少而精（≤15 个），每个都有明确「看什么、多久看一次」。失效的及时删。

## 每日/隔日扫一眼（5-10 分钟）

| 来源 | 看什么 | 频率 |
|---|---|---|
| Hugging Face Daily Papers | 社区投票的当日论文榜，agent/RL 主题优先 | 每天 |
| arXiv: cs.CL / cs.LG 新提交（用关键词过滤：RLHF, GRPO, agentic, RL agent, post-training） | 第一手新论文 | 每天/隔天 |
| Twitter/X：关注 DeepSeek / Qwen(Alibaba) / Moonshot / MiniMax / Anthropic / OpenAI / Meta AI 研究员账号 | 新发布的第一信号 | 每天 |

## 每周看一次

| 来源 | 看什么 | 频率 |
|---|---|---|
| Interconnects（Nathan Lambert 的 newsletter） | 后训练领域最好的周度评论与分析 | 每周 |
| AlphaSignal / The Batch 等 AI newsletter | 一周要闻兜底，防遗漏 | 每周 |
| GitHub Trending + verl / OpenRLHF / TRL 的 Release Notes | 新框架能力、新 recipe 落地 | 每周 |
| 知乎「大模型」、机器之心 | 中文社区视角，粗读 | 每周 |
| YouTube: 论文精读频道（按需） | 难懂论文的辅助讲解 | 每周 |
