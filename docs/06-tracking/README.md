# 06 · 持续学习跟踪（Tracking）

> 这个领域的论文速度快到「学不过来」，所以靠系统而不是靠意志力：**固定信息源 + 每周固定仪式**。
> 每周投入 1-2 小时维护，长期复利。

## 每周仪式（建议周日，30-60 分钟）

1. **收集**：过一遍 [sources.md](sources.md) 的信息源，把候选论文丢进 `04-papers/inbox/` 登记
2. **筛选**：按「与当前 ROADMAP 阶段相关度」选出本周 1-3 篇精读，其余标预计阶段
3. **精读**：按 `templates/paper-note.md` 写笔记（可以丢给 ZCode 先出一版草稿再人工过公式）
4. **沉淀**：新概念/连线 → 更新知识图谱 → 重跑 `build_graph.py`
5. **回顾**：按 `templates/weekly-digest.md` 写本周周报，存 `weekly/`（命名 `YYYY-Www.md`）
6. **计划**：看 ROADMAP 进度，定下周的 3 个重点

## 目录

- `sources.md`：信息源清单（定期增删，保持 ≤ 15 个，多了就不看了）
- `weekly/`：周报归档，第一份是 [2026-W38.md](weekly/2026-W38.md)

## 信号判断：什么值得精读

- 改变了你对某个已学算法的认知（推翻/修正/大幅简化）
- 与你当前阶段直接相关，且有可复现的实验细节
- 来自可信团队且有开源代码/数据
- 反例：纯 benchmark 刷榜、只换数据不换方法、营销型技术报告——粗读记一行即可
