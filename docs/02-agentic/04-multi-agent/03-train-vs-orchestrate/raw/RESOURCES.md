## 收束要点

- 本讲框架刻意保守（编排先行）：因为训练的沉没成本高、可逆性差；但注意「Bitter Lesson」提醒我们长期看被训练的通用能力会胜出——两条公理的时间尺度不同
- 建议把决策树打印出来贴在工位：每次「要不要上训练」的争论都过一遍树
