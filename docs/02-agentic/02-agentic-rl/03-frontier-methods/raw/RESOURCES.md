## 精读要点

- GiGPO 与 PRM 式过程奖励的对比是核心问题：一个「免模型、靠组内对比」，一个「训练过程打分器」——GiGPO 论文有直接消融，注意其任务都是「结构同构」的 agent 任务（对齐假设成立的前提）
- WebRL 的失败驱动出题里有个容易被忽略的细节：变体任务要经过「可解性校验」（确保新变体确实有解），否则课程会教出错误目标
